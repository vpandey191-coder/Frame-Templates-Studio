# Frame-Templates-Studio
Frame-Tamplets- Studio — a browser-based tool that turns images, videos, PDFs, EPUBs, and text files into one compressed, stylishly framed PDF.  Features in this first version: - Upload up to 10 files (images, video, PDF, EPUB, text) - Six PDF frames (Classic, Cinema, Gallery, Grid 4-up, Magazine, Minimal) - Compression presets: Light.
